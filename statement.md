# Project Statement

## Problem Statement
Managing student grades manually can make adding, updating, deleting, searching, and reviewing records inconvenient and error-prone. The project provides a small command-line system that organizes student names and grades in a structured digital record.

## Scope
The project covers local student-grade record management through a command-line interface. It includes CRUD operations, search, grade-summary reporting, JSON persistence, validation, and automated tests. It does not include authentication, cloud deployment, multi-user access, or a web interface.

## Target Users
- Students learning Python programming
- Teachers or instructors demonstrating basic record management
- Small academic demonstrations requiring simple grade records

## High-Level Features
1. Student creation
2. Grade update
3. Student deletion
4. Student listing
5. Student search
6. Grade summary
7. Persistent JSON storage
8. Input validation and error handling
9. Automated unit tests
